Hosting decision
BOTH APPS STILL REQUIRE NEXT AS CURRENTLY BUILT. Static export is not verified.
Both next.config.mjs files use output=standalone. Existing app ports are unchanged
(user Docker 3000, admin 3001). Parent owns Compose/Caddy/Docker/bootstrap changes.

Each app's only Next API handler is src/app/api/[...path]/route.ts:
GET/POST/PUT/PATCH/DELETE/OPTIONS/HEAD, transport only.
It streams multipart/auth/cookies/statuses through to Go and returns explicit
502/503 failures when unavailable. There are NO Node business implementations.

GO_API_INTERNAL_URL is read at request time. BACKEND_INTERNAL_BASE_URL is a legacy
fallback, then http://127.0.0.1:8080. Use an internal HTTP(S) origin without embedded
credentials, path, query or fragment. Browser API requests stay same-origin /api.
The proxy preserves Origin; Go must allow the actual UI origin.
